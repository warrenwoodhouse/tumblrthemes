# install
How to Install my Themes

[!IMPORTANT] Before installing my themes, let me know in advance if you intend to use my themes on a commerical use blog. [CLICK HERE](https://warrenwoodhouse.blogspot.com/contact) to get in touch. My themes are free for personal use only and for commerical use upon request via the contact form.

1. Finf my theme above and select the Install Theme link
2. Copy the HTML Code on the page available
3. Log into Tumblr by [CLICKING HERE](https://www.tumblr.com/login)
4. Select the blog you would like the theme to be used on
5. Head to **Edit appearance** and then select **Edit theme**
6. Click the **Edit HTML** button near the top of the customization menu
7. Click inside the code box, select all existing code and delete it
8. Paste your new theme code into the box
9. Click **Update Preview** to make sure the layout loads correctly
10. Click **Save** and then exit back to the customization menu. Here, you can add any extra theme options if available
